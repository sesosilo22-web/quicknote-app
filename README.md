# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organise, search and delete notes. Each note has a category and creation date, and notes are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes with a text input.
- Choose a category: Personal, Work or Study.
- Display notes with their category and creation date.
- Delete individual notes.
- Search notes by text.
- Validate empty notes.
- Limit notes to 200 characters.
- Display the correct number of notes.
- Save notes to localStorage.
- Load saved notes when the page opens.
- Responsive layout for smaller screens.
- Different visual styles for each note category.

## How to Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. You can then add, search and delete notes.
